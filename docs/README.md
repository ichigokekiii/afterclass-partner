# Docs

This folder is the working record for the After Class partner app. It is not the product spec. The spec does not exist yet.

Read these in order when you pick the work back up.

| File | Mode | What it is for |
| --- | --- | --- |
| `docs/explanation-student-product.md` | Explanation | What the June 20, 2026 After Class repo is, and what that leaves open for a café app. |
| `docs/reference-repo-facts.md` | Reference | File map, types, sample venues, and which talk claims appear in that commit. |
| `docs/progress.md` | Working log | What this effort has done, what it has not done, and the next gate. |
| `docs/design-sections.md` | Proposal | Design sections as they are presented. A section is decided only after an explicit yes. |
| `docs/wireframes/` | Explanation and reference | Assessment of the student-app wireframe boards. Start at `docs/wireframes/README.md`. |
| `docs/direction/` | Explanation and reference | Reference shots, the counter-app direction, and the first Swift build. Start at `docs/direction/README.md`. |

Add a new file when a new mode needs a home. Do not park a design decision in the reference, and do not park a lookup table in the explanation.

The design spec, when it exists, goes in `docs/superpowers/specs/`. That file is a later step. It needs a written design and an explicit yes before anyone writes it.
