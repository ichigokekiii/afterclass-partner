# Partner app direction

This is the proposed look and the proposed build for the café phone. It is not the spec, and no Swift has been written from it yet.

The four pictures are references for structure. They are other people's products. The student wireframes are in `docs/wireframes/`. Color, type, and marks come from `design-sheet.png`. The partner primary is burgundy `#4A1525`. The pink `#F39394` is the student app. The screen background is cream `#FEF9E6`.
