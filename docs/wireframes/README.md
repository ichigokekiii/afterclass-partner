# Main-app wireframes

These notes are about two boards of the student app. They are not a spec for the café phone, and they do not approve the architecture in `docs/design-sections.md`.

Source. Two images attached on 2026-10-15. Copies live next to this file.

| File | Mode | What it is for |
| --- | --- | --- |
| `board-discovery.png` | Source | Photo card, prompts, and the prompt overlay. Frame titles are printed on the board. |
| `board-meetup.png` | Source | Calendar, times, map, and the café sheet. This board has no frame titles. |
| `reference-frames.md` | Reference | What each frame shows. |
| `explanation-assessment.md` | Explanation | What the boards do well, where they break the product, and what they still leave to the café app. |

The owner of this pass is a read of the pictures. Nothing in the app was redesigned from them.
